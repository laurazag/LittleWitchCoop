LITTLE WITCH CO-OP 0.10.6 — EXPERIMENTAL

INSTALL
Extract the entire ZIP. Close the game. Run Install.cmd and paste the game
folder containing LWIW.exe (Steam - Manage - Browse local files).
Setup and uninstall instructions are always in English.
It does not change Windows language or execution-policy settings.
An existing plugin DLL is backed up; saves, translation and mod settings remain.
Another conflicting winhttp.dll is not overwritten.

PLAY
Install the same version on all PCs. Launch through Steam and load a save.
F2 opens the connection panel. Y opens chat. B opens emotes while connected.
Public Steam rooms: Steam rooms tab - choose slots - enable Public - Create.
Private Steam rooms: disable Public and create. Copy the code from that same
page using the copy icon. Your guest pastes it in Connection - Code - Join.
No friend connection or Radmin is required for the code invitation flow.
This latest private-code flow still needs real testing between two accounts.
Code expires with the room. Share the full case-sensitive code, including LW-.
IP/Radmin remains available through the Connection tab.
Each player uses their own save/progress/resources; players must be in the same
area to see one another. Names and chat messages are not translated.

LIMITS / TEST STATUS
Up to 99 slots including host is experimental. 99 roster/chat entries were
simulated; larger real-player sessions and performance have not been validated.
Two-PC Steam public browsing/joining and Radmin were confirmed in earlier builds.
The private code normally has 30 characters, with a copy icon inside the field in the Steam rooms tab.
Click +/- once or hold to accelerate 1/5/10/20 slots.
Kick/ban alerts block local input until confirmed.

ASSETS
The public archive uses the built-in chime and game/system font fallback.
Minecraftia and personal WAVs are not bundled in the public archive.
Custom WAV instructions: EMOTE-SOUNDS.txt (PCM16, <=5 seconds, <=2 MB).
Emoji credits and licenses are included with the plugin; BepInEx license included.
If an issue occurs, keep BepInEx/LogOutput.log and Unity Player.log.

UNINSTALL
Close the game, run Uninstall.cmd and enter the game folder.
Only the bundled co-op plugin files are removed. BepInEx, other mods, saves,
translation, config, bans, custom WAVs, backups and extra plugin files remain.
The installer does not detect or change the Windows language. In-game language still follows Windows by default and can be changed from the F2 settings gear.
